# Лабораторная 2. Кластеризация методом K-means

Блокнот: [HW2_KMeans.ipynb](HW2_KMeans.ipynb)

## Задача

Провести кластерный анализ набора данных Economics of Cities методом K-means, определить подходящее количество кластеров, обосновать выбор и интерпретировать полученные группы городов.

## Данные

**Economics of Cities**: экономические условия в 48 городах мира в 1991 году (банк Union, Швейцария).

| Признак | Описание |
|---------|----------|
| `City` | Название города |
| `Work` | Среднее число рабочих часов в год по 12 профессиям |
| `Price` | Индекс цен 112 товаров и услуг, включая аренду (Цюрих = 100) |
| `Salary` | Индекс зарплаты за час работы после налогов (Цюрих = 100) |

В ходе предобработки удалены две записи с некорректными значениями `-9999` (Каир и Джакарта). Для анализа использованы 46 городов.

## Ход работы

1. **Предобработка:** удалены записи с некорректными значениями `-9999`.
2. **Стандартизация:** признаки `Work`, `Price` и `Salary` приведены к единому масштабу с помощью `StandardScaler`.
3. **Выбор количества кластеров:** исследованы значения K от 2 до 8 с использованием метода локтя.
4. **Оценка качества:** рассчитаны метрики Silhouette Score, Calinski-Harabasz и Davies-Bouldin.
5. **Кластеризация:** выполнено разбиение данных на 3 кластера с помощью K-means.
6. **Интерпретация:** проанализированы средние значения признаков и состав полученных кластеров.
7. **Визуализация:** построены графики распределения городов и профилей центров кластеров.
8. **Сравнение методов:** результаты K-means сопоставлены с иерархической кластеризацией методом Уорда с помощью Adjusted Rand Index (ARI).

## Результаты

По результатам исследования выбрано **3 кластера**. При этом метрики качества не указали на единственное оптимальное значение K: Silhouette Score и Calinski-Harabasz отдают предпочтение двум кластерам, а Davies-Bouldin — восьми. Значение K = 3 выбрано с учётом возможности содержательной интерпретации полученных групп.

Средние значения признаков по кластерам:

| Кластер | Work | Price | Salary |
|---------|------|-------|--------|
| 0 | 1855.45 | 50.78 | 16.59 |
| 1 | 1789.24 | 84.97 | 59.03 |
| 2 | 2133.50 | 54.17 | 16.08 |

Выделены следующие группы городов:

- **Кластер 0:** города с относительно невысокими ценами и заработной платой, а также обычной продолжительностью рабочего времени.
- **Кластер 1:** города с наиболее высокими значениями индексов цен и заработной платы и относительно небольшим количеством рабочих часов.
- **Кластер 2:** города с низкими значениями индексов цен и заработной платы и наиболее продолжительным рабочим временем.

## Сравнение с иерархической кластеризацией

Для оценки сходства результатов K-means и метода Уорда рассчитан Adjusted Rand Index.

Получено значение **ARI = 0.862** при сравнении двух разбиений на 3 кластера. Это свидетельствует о высокой степени сходства результатов двух методов.
