# Лабораторная работа 3. Кластеризация DBSCAN

Блокнот: [lab3.ipynb](lab3.ipynb)

## Задача

Провести кластерный анализ набора данных *Economics of Cities* с помощью алгоритма DBSCAN. Изучить влияние параметров `eps` и `min_samples` на результат кластеризации, определить плотные группы объектов и выявить шумовые наблюдения.

Дополнительно сравнить результаты DBSCAN с K-means и иерархической кластеризацией методом Уорда с использованием Adjusted Rand Index (ARI).

## Данные

Используется набор данных `Econom_Cities_data.csv`, содержащий информацию об экономических показателях городов.

Для кластеризации используются три признака:

- `Work` — рабочее время;
- `Price` — уровень цен;
- `Salary` — уровень заработной платы.

В исходном наборе содержится 48 городов. Две записи — Cairo и Jakarta — содержат некорректные значения `-9999`. После их исключения остаётся 46 наблюдений.

Перед кластеризацией признаки стандартизируются с помощью `StandardScaler`.

## Ход работы

1. **Предобработка данных**
   - Загрузка набора данных.
   - Обнаружение и исключение записей с некорректными значениями `-9999`.
   - Выбор признаков `Work`, `Price` и `Salary`.
   - Стандартизация признаков.

2. **Изучение алгоритма DBSCAN**
   - Рассмотрены понятия ε-окрестности, ядровых, граничных и шумовых точек.
   - Изучено влияние параметров `eps` и `min_samples` на формирование кластеров.

3. **Подбор параметров**
   - Построены графики k-distance для `min_samples = 4, 5, 6`.
   - Исследованы различные комбинации `eps` и `min_samples`.
   - Для оценки результатов использовались количество кластеров, число шумовых объектов и Silhouette Score.

4. **Кластеризация**
   - Выполнена кластеризация с выбранными параметрами `eps = 0.9` и `min_samples = 5`.
   - Определены состав и размеры кластеров.
   - Рассчитаны средние значения признаков для каждой группы.

5. **Сравнение алгоритмов**
   - Результаты DBSCAN сопоставлены с K-means и иерархической кластеризацией методом Уорда.
   - Для сравнения использована метрика Adjusted Rand Index (ARI).

## Результаты

### Выбранные параметры DBSCAN

| Параметр | Значение |
| --- | ---: |
| `eps` | 0.9 |
| `min_samples` | 5 |
| Количество кластеров | 2 |
| Количество шумовых объектов | 8 |
| Доля шума | 17.39% |
| Silhouette Score | 0.512 |

Выбранная комбинация параметров представляет собой компромисс между количеством выделяемых кластеров и долей шумовых объектов. Однозначного оптимума по всем рассмотренным показателям выявлено не было.

Silhouette Score рассчитан без учёта шумовых объектов.

### Размеры кластеров

| Группа | Количество городов |
| --- | ---: |
| Кластер 0 | 19 |
| Кластер 1 | 19 |
| Шум | 8 |
| **Всего** | **46** |

### Средние значения признаков

| Группа | Work | Price | Salary |
| --- | ---: | ---: | ---: |
| Шум (-1) | 1900.38 | 99.92 | 61.26 |
| Кластер 0 | 1792.00 | 77.53 | 55.16 |
| Кластер 1 | 1959.21 | 50.12 | 14.79 |

Кластер 0 характеризуется относительно более высокими значениями `Price` и `Salary`, а также меньшим средним значением `Work`.

Кластер 1 отличается более низкими значениями `Price` и `Salary`, но более высоким средним значением `Work`.

Шумовые объекты имеют наиболее высокие средние значения `Price` и `Salary` среди выделенных групп. Они не образуют достаточно плотных окрестностей, чтобы быть отнесёнными к одному из двух кластеров.

### Сравнение алгоритмов

Для сравнения результатов кластеризации рассчитан Adjusted Rand Index:

| Сравниваемые алгоритмы | ARI |
| --- | ---: |
| K-means и DBSCAN | 0.525 |
| Ward и DBSCAN | 0.520 |
| K-means и Ward | 0.862 |

K-means и иерархическая кластеризация методом Уорда показали наиболее близкие результаты — ARI составляет 0.862.

Сходство DBSCAN с двумя другими алгоритмами ниже и составляет около 0.52. Это связано с различиями в принципах работы методов: K-means и Ward формируют разбиение всех объектов, тогда как DBSCAN дополнительно выделяет шумовые наблюдения.

## Вывод

В ходе работы был изучен алгоритм DBSCAN и проведена кластеризация 46 городов по трём стандартизированным экономическим признакам.

При выбранных параметрах `eps = 0.9` и `min_samples = 5` алгоритм выделил два кластера по 19 городов и определил 8 шумовых объектов (17.39% выборки). Полученные группы различаются прежде всего по средним значениям стоимости жизни и заработной платы.

Сравнение с другими методами показало, что результаты K-means и иерархической кластеризации Уорда наиболее близки друг к другу (ARI = 0.862). Сходство DBSCAN с ними ниже (ARI = 0.525 и 0.520 соответственно), что отражает особенности плотностного подхода и выделения шумовых объектов.
